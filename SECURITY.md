# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.4.x   | yes       |
| < 0.4   | no        |

## Reporting a Vulnerability

Please email louis-felix.nothias@cnrs.fr with the subject line
"SECURITY: indicium-adapters" rather than opening a public issue.
You can expect an acknowledgement within 7 days.
